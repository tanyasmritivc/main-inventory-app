Geist and Geist Mono, weights 400 and 500, are served locally by next/font/local.
These unmodified font files were fetched from Google's official font distribution
on 2026-10-18. Keeping them in the release removes an external build dependency.

Sources:
- https://fonts.googleapis.com/css2?family=Geist:wght@400;500&family=Geist+Mono:wght@400;500&display=swap
- https://github.com/google/fonts/tree/main/ofl/geist
- https://github.com/google/fonts/tree/main/ofl/geistmono

Both families use the SIL Open Font License in OFL.txt.
