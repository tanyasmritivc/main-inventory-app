# Mobile branding v5

Local branch `mobile-brand-v5`. No push, version bump or TestFlight upload.

The existing SVG brand widgets now read the supplied black/reversed Petals assets. Old asset names alias new artwork. The bundled onboarding scene retains its existing geometry and animation; only its logo material changed from orange to ink. Other orange highlights remain.

The main iOS icon is the opaque black glow tile. All catalog entries were regenerated from the supplied 1024px PNG, including the existing dark appearance entry. Android launcher icons were regenerated by the existing launcher-icons configuration. There is no alternate-icon switching support, so no new switching feature was added.

Launch screen: white, centered ink mark at 96pt, with 96/192/288px images. The launch frame was captured in the iPhone 17 Pro simulator and shows the centered black mark.

Generated icon pixel sizes: 20, 29, 40, 50, 57, 58, 60, 72, 76, 80, 87, 100, 114, 120, 144, 152, 167, 180, 1024. Android: 48, 72, 96, 144, 192. `tool/export_brand_v5.dart` reproduces catalog and launch exports.

Runtime SVG C2PA metadata was removed because flutter_svg warns on that nonvisual element. Original supplied SVGs remain intact in this design reference folder.

Validation: Flutter analyze has no issues; 50 branding, launch and chat onboarding tests pass; final iOS simulator build passes. Home screen icon, launch screen, authentication wordmark and black 3D onboarding mark were visually inspected. Settings has no existing logo to replace, so no layout was added. No authentication or inventory behavior changed.

Non-logo orange remains in app_theme, auth focus/seed colors, place_ui, pip_extract_loader accents, chat onboarding scan hints, onboarding world/scene/sample scan, world composer and world style. Existing UI colors were not changed.
