# FindEZ Space polish: handoff for Codex

**What's in this folder:**

- `CODEX_PROMPT_TESTFLIGHT.md`: the prompt to paste into Codex.
- `screens/current-space.png`: the screen as it is now.
- `grain.png`: a fallback grain texture, only used if the app doesn't already have one.

**How to use it:**

1. Unzip this folder into the repo at `docs/space-polish/`.
2. Open Codex from the repo root on your Mac.
3. Paste everything below the line in `CODEX_PROMPT_TESTFLIGHT.md`.
