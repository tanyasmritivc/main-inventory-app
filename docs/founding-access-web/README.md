# FindEZ web: Founding Access modal, handoff for Codex

**What's in this folder:**

- `CODEX_PROMPT_WEB.md`: the prompt to paste into Codex.
- `findez-web-founding-access.html`: the approved design. Use the Demo bar at the bottom left to switch between After sign up / After sign in and Dark / Light.
- `screens/`: each state, including the small-screen sheet.

**How to use it:**

1. Unzip this folder into the repo at `docs/founding-access-web/`.
2. Open Codex from the repo root.
3. Paste everything below the line in `CODEX_PROMPT_WEB.md`.
4. Codex works on `feat/founding-access-web` and pushes that branch, which gives you a Vercel preview. It doesn't merge into main or deploy to production.
