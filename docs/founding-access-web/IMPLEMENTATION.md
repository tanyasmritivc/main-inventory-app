# Founding Access web implementation

## Entry points and scope

Sign-in and sign-up complete in `components/site/auth-form.tsx` and the existing `/auth/callback` page. `lib/auth-callback.ts` normalizes the first destination to `/worlds` or the existing safe requested route. AppShell already reads Supabase `getSession().user`; this change also reads its `created_at`, without new authentication calls or changes to auth routing. Plans & usage is `/settings/plans`, rendered by PlansUsageClient. Existing Inter, Inter Tight and Plus Jakarta Sans load in the root layout; `interior-tokens.css` owns current theme tokens. Existing Radix Dialog and Button are reused. No analytics exists; none was added. There was no toast system, so Get started uses a small scoped accessible status message.

The older PlanIntroduction launch is replaced in AppShell to avoid duplicate welcomes. Its helpers and billing controls remain untouched. A 600ms settle delay waits for other open dialogs to close. Every user dismissal stores `findez_founding_seen_<userId>`; storage errors fall back to session memory. The provider binds requests to the current account and guards public routes. New accounts under 15 minutes receive signup copy; older accounts receive returning copy. The Plans card opens Your plan directly without Back. No API calls, billing/entitlement logic, limits, saved records, schema, mobile, public pages, Upgrade button or account menus changed.

The component uses current `--text`/`--text2`/`--muted-text` equivalents of the prototype tokens. Secondary fine print uses the theme's accessible muted colour rather than the lower-contrast reference tertiary grey. The existing white FindEZ clove asset is reused. Four reference palettes are exported from `lib/riso-palettes.ts`; existing Space artwork is unchanged. Reduced Motion retains fades while disabling art drift/pop/rise and button movement. Radix supplies focus containment, Escape/outside dismissal and background scroll locking; focus starts on the dialog container and returns to the opener.
