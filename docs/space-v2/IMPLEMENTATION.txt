Deliberate differences from sample-only prototype features
- Saved InventoryItem records have no Review flag/count. Review still opens the
  existing draft queue on tap or long press; no invented count, dots or filter.
- Existing chat scope is inventory-wide, not Space-only. No unsupported scope
  switcher or inferred inventory count is shown.
- Scan Photo retains the existing Camera / Library chooser. Separate direct
  source rows would require changing the capture flow outside this UI scope.
  Barcode capture remains available alongside import and Type it in.
- More retains actual app actions in their original order. Sample-only Select,
  Export, Rename and Delete actions are not invented.
- Move lists real Spaces; unavailable per-Space counts are omitted.
- The current item model has no standalone units field. Imported units/custom
  columns remain in their original imported details.
- Manufacturer lookup, checkout, documents, photo gallery, QR sharing and other
  comprehensive item actions remain in the unchanged full detail editor.
- Existing lazy slivers are retained rather than adding artificial 60-row fetches.
