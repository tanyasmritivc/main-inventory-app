# FindEZ Space v2: handoff for Codex

**What's in this folder:**

- `findez-space-prototype.html`: the working prototype. Open it in a browser and click through it. This is the design to copy.
- `screens/01-top.png` to `15-back.png`: each step of the prototype.
- `before-after.png`: the current app next to the new design.
- `overview.png`: all the steps on one sheet.
- `CODEX_PROMPT.md`: the prompt to paste into Codex.

**How to use it:**

1. Put this whole folder in the repo at `docs/space-v2/`.
2. Open Codex from the repo root.
3. Paste everything below the line in `CODEX_PROMPT.md`.
4. Review the branch `feat/space-v2-ui` before merging. Codex doesn't push.

**Ground rule:** this changes the UI and design only. Item names, imported column names, fields, field order, values and item settings all stay exactly as they are today, whether the items came from Auto Extract, a spreadsheet or were typed in.
